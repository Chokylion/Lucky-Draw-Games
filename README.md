# Lucky Draw Games

Three offline random-draw machines for events. Open an HTML file in a browser (or run the `.cmd` launcher on Windows):

- `Gacha.html` — KAIZEN gacha
- `Wafer.html` — wafer-probe themed draw
- `Spooky.html` — Halloween randomizer

Load a roster from an Excel file (`.xlsx`) with a name column and an optional employee-ID column; winners can be exported back to Excel. Everything runs locally in the browser. No server, no API keys, no data is included in this repo.
